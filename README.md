## Обо мне

Студент экономического факультета, который пишет код. Интересуюсь полным циклом разработки продукта: от постановки задачи и архитектуры до интерфейса и развёртывания. Из любви к деталям иду в сторону, где разработка пересекается с экономикой — unit-экономика, тарификация, продуктовые метрики.

Что делаю сейчас:

- Развиваю **workdo.ru** — SaaS-платформу, основатель проекта.
- Руковожу филиалом **«StartUp Space ВГТУ»** — это предпринимательское сообщество при университете: с 27 мая 2026 года помогаю студентам превращать идеи в работающие проекты.
- Собираю портфолио из хакатонов, конкурсов и исследовательских работ.

Принципы, по которым работаю:

- Сначала понять задачу целиком, потом писать код. Последние три хакатона выиграны или взяты в финал именно за счёт этого.
- Не брать фреймворк, пока не понимаю, что он делает под капотом. Проект [iaai](https://github.com/glcskl/iaai) — нейросеть с нуля на чистом NumPy, без `fit()`, именно с этой мысли.
- Доводить до рабочего состояния, а не до «написал и забросил». У каждого хакатонного проекта есть README с инструкцией запуска.
